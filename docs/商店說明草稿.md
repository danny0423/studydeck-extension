### 詳細說明

```
在任何網站選一個字，按右鍵 →「加到 StudyDeck 待學習」，就會：

・查出意思、讀音、原形、詞性
・連同那一句一起存成例句
・跳通知告訴你加好了

之後到 StudyDeck「你的資料庫 → 待學習」勾幾個字，就能做成學習集。
```

## 隱私權分頁

### 單一用途

```
把使用者在網頁上選的單字和所在的句子，存到使用者自己的 StudyDeck 待學習清單。
Saves words the user selects on web pages, with their sentence, to the user's own StudyDeck to-learn list.
```

### 權限理由

| 權限 | 理由 |
| --- | --- |
| `contextMenus` | 在選字時的右鍵選單加上「加到 StudyDeck 待學習」。Adds the right-click menu item for selected text. |
| `activeTab` | 只在使用者按下右鍵選單時，讀取目前這一頁選取的文字。Reads the selection on the current tab only when the user clicks the menu item. |
| `scripting` | 按下右鍵選單時，在目前這一頁執行一小段程式，抓出選的字所在的那一句。Runs a small script on the current tab, only when the user clicks the menu item, to get the sentence around the selected word. |
| `storage` | 在瀏覽器裡記住使用者填的 StudyDeck 網址和登入憑證。Stores the StudyDeck address and login token locally. |
| `notifications` | 告訴使用者單字有沒有加成功。Tells the user whether the word was saved. |
| 主機權限（`https://*/*`，選用） | 使用者在設定頁填好 StudyDeck 網址後，只請求那一個網址的權限，用來呼叫 StudyDeck。Requested at login for the single StudyDeck address the user enters, to call its API. |

### 遠端程式碼

選「**否**」。所有程式都在上傳的 zip 裡。

### 資料使用

勾這兩項：
- **驗證資訊（Authentication information）**：登入用的帳號、密碼，以及登入後拿到的憑證
- **網站內容（Website content）**：選的字和那一句

然後勾選三項聲明（不出售、不用在無關用途、不用來判斷信用）。

## 測試說明（給審核員）

⚠️ 審核員連不到 Tailscale 裡的 StudyDeck，一定要用 AWS 公開版＋專用測試帳號。帳密只貼在後台，**不能寫進這個 repo**。

| 欄位 | 內容 |
| --- | --- |
| 帳號 | 在 https://quizlet.danny0423.com 用邀請碼註冊的專用測試帳號（不要用自己的帳號） |
| 密碼 | 那個測試帳號的密碼 |

```
This extension requires a StudyDeck account. Please use the test account provided.

StudyDeck URL: https://quizlet.danny0423.com

Steps:
1. After installing, the settings page opens automatically. (If it doesn't: right-click the extension icon in the toolbar and choose "Options".)
2. Enter the StudyDeck URL above and log in with the test account. When Chrome asks for permission to access that address, click "Allow".
3. Open any web page with English or Japanese text (for example https://en.wikipedia.org/wiki/Tokyo), select a word, right-click, and choose "加到 StudyDeck 待學習" (Add to StudyDeck to-learn list).
4. A notification confirms the word was saved. Click the extension icon to see it in the list, or log in at the StudyDeck URL above and open 你的資料庫 (Your library) → 待學習 (To learn).
```

測試帳號審過也不要刪：之後每一版送審，審核員都可能再測一次。
